# Cardápio Digital Web — Maison Royale

Projeto da atividade de Programação para Internet.

## Arquivos
- `index.html` — estrutura da página
- `style.css` — aparência e responsividade
- `script.js` — 150 produtos, filtros, pesquisa, carrinho e cálculos

## Publicação
1. Crie um repositório no GitHub.
2. Envie os três arquivos.
3. No GitHub: Settings → Pages → Deploy from a branch → selecione `main` e `/root`.
4. Aguarde a publicação.
5. O endereço será semelhante a `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Requisitos atendidos
- 30 entradas
- 30 pratos principais
- 30 sobremesas
- 30 bebidas
- 30 vinhos
- Pesquisa e filtro
- Carrinho “Meu Pedido”
- Quantidade e remoção
- Subtotal
- 10% opcional
- Nome e mesa
- Finalização com resumo e número do pedido
- Responsividade
- Extras: ordenação, observações e número automático do pedido
